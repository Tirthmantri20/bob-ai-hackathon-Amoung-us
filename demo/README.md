# Demo Artifacts

This folder contains the demonstration artifacts for the Bob AI Hackathon submission.

## Contents

- `demo-video-link.txt`: URL link to the walkthrough / demo video.
- `live-demo-url.txt`: URL to the deployed web application (or `NOT DEPLOYED`).
- `screenshots/`: Key application screenshots showcasing the solution:
  - `01-home-dashboard.png`: Operations dashboard overview with active shipments and alerts.
  - `02-query-input.png`: Autonomous agent / natural language risk query input.
  - `03-result-output.png`: AI risk evaluation, cold-chain mitigation, and route optimization output.
